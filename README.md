# 放洋留遊學 語言學校報價系統

## 專案結構

```
index.html     主結構 HTML，引用 app.js
app.js         所有 JS 邏輯、計算引擎、UI 函數
```

## 部署方式

GitHub Pages：將 `index.html` 與 `app.js` 放在同一目錄，開啟 GitHub Pages 即可。

## 計算架構（六層）

```
外幣原始成本（學費 + 住宿 + 規費 + 加購）
  ↓
× (1 − 廠商折扣%)         ← 學校給放洋的優惠，折在成本上
  ↓
× 匯率 × (1 + 匯差緩衝%)  ← 台幣成本
  ↓
× (1 + 顧問獎金%)          ← 未稅售價
  ↓
− 公司折扣                  ← 顧問選擇的折扣類型
  ↓
× (1 + 營業稅%)             ← 含稅售價（給學生）
  ↓
淨利試算（管理員）= 稅前收入 − 台幣成本 + 回傭
```
